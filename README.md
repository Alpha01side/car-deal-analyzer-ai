# Luxury Wardrobe Category Experience

A standalone premium e-commerce category navigation prototype that presents merchandise categories inside an interactive luxury wardrobe. The wardrobe slides horizontally with arrows, drag, swipe, wheel input, inertia-based navigation, and snap-to-category behavior.

## Run locally

Open `index.html` in a browser, or serve the folder with a static server:

```bash
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173/index.html`.
